## 📚 How to Use

### Quick Start (5 minutes)
```bash
# 1. Clone repository
git clone https://github.com/arsalan507/Script-automation.git
cd Script-automation

# 2. Install dependencies
npm install

# 3. Add API keys to .env.local
echo 'GEMINI_API_KEY=your-key' > .env.local
echo 'OPENAI_API_KEY=sk-your-key' >> .env.local

# 4. Run development server
npm run dev

# 5. Open browser
open http://localhost:3000
```

### Complete Workflow
1. **Phase 0**: Fill in user context form
   - Niche, category, product, target audience, outcome, duration
2. **Upload**: Drag & drop viral reel video (MP4, MOV, AVI)
3. **Wait**: System processes through 5 phases (2-4 minutes)
4. **Review**: Comprehensive results with:
   - Gemini analysis (transcription, checklist, scores)
   - Replication evaluation (feasibility, verdict, modifications)
   - Complete shooting script (scenes, dialogue, direction)
   - Script evaluation (quality scores, passed/failed sections)
   - Final polished script (post-revision)
5. **Download**: Export complete JSON report
